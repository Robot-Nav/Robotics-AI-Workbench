# AI 驱动研发

目标是把 AI Agent 接入真实研发流程，让研究、编码、测试、仿真和实验分析形成可追踪闭环。

## 典型工作流

1. Research Agent：阅读论文、官方文档和源码。
2. Design Agent：分析现有架构，提出修改计划。
3. Coding Agent：在隔离分支中实现功能。
4. Testing Agent：执行编译、单元测试和仿真。
5. Review Agent：检查代码质量、接口兼容性和安全风险。
6. Reporting Agent：汇总日志、指标、失败案例和结论。

AI 生成的代码必须经过测试和人工审查；涉及真机运动的变更必须经过安全验证。
