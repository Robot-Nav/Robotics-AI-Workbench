# 问题与解决方案知识库

这里记录学习、开发、仿真、部署和真机实验中遇到的问题。目标不是收集报错文本，而是沉淀可复用的排障方法。

## 每条记录至少包含

- 问题现象与预期行为。
- 操作系统、硬件、软件版本和配置。
- 最小复现步骤与完整日志。
- 排查过程和被排除的假设。
- 已确认根因（区分推测与事实）。
- 修复方案、验证命令和结果。
- 预防措施与相关资料。
