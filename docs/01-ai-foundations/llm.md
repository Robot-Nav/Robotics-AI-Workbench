# 大语言模型 LLM

## 需要掌握的概念

- **Tokenization**：文本如何切分为模型处理的离散单元。
- **Embedding**：Token 映射到向量空间的表示。
- **Transformer**：以注意力机制为核心的序列建模架构。
- **Attention**：根据 Query、Key、Value 建立上下文相关的信息交互。
- **Context Window**：单次推理能够处理的上下文长度。
- **Pre-training / Post-training**：基础能力学习与指令对齐、偏好优化。

## 工程关注点

记录模型版本、上下文长度、输入输出 Token、结构化输出约束、工具调用格式、响应延迟和失败样例。

## 机器人场景

LLM 可用于任务理解、自然语言交互、任务分解和知识查询，但不应未经安全约束直接输出高频底层电机控制指令。
