## 核心研发闭环

1. **Research**：检索论文、阅读源码、理解算法。
2. **Design**：明确问题、约束、系统架构与评价指标。
3. **Build**：使用 AI 辅助编码，完成模块实现与集成。
4. **Test**：运行单元测试、仿真、回归和真机验证。
5. **Analyze**：自动采集日志、分析指标、定位失败原因。
6. **Learn**：把验证过的知识和解决方案沉淀到知识库。

## 使用方式

- 左侧目录按技术方向浏览。
- 顶部搜索框检索算法、术语和历史问题。
- 文章底部点击“在 GitHub 上编辑此页”，直接在线修改。
- 每次解决有价值的问题，都在问题知识库中建立一条记录。

**原则：区分理论理解、代码实现、仿真验证和真机验证，不把未经验证的推测写成结论。**
