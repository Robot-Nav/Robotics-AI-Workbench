Offer 沟通问题清单

校招及求职沟通参考 · 6 个类别 · 37 个问题

岗位职责与技术发展 薪酬与绩效 试用期与应届生政策 五险一金、落户与人才政策 年假、福利、工作时间与出差 职业发展、内部转岗与劳动合同

一、岗位职责与技术发展

  1. 岗位实际职责是什么？日常工作主要偏算法研发、技术预研，还是工程集成与项目交付？
  2. 团队目前主要负责哪些项目和技术方向？项目处于研发阶段、产品落地阶段还是量产交付阶段？
  3. 入职后的前 3～6 个月，通常安排哪些工作内容和考核目标？是否有机会独立负责算法模块？
  4. 目前团队和算法研发团队分别有多少人？是否有专门的技术负责人或导师？
  5. 算法研发、仿真训练、真机部署和现场交付各自大概占多少工作时间？
  6. 团队是否配备真实机器人实验平台、仿真训练平台和 GPU 算力？
  7. 算法主要由团队自主研发，还是基于开源框架进行二次开发？是否有持续的技术预研和迭代计划？
  8. 这个岗位是新增 HC 还是人员补充？团队未来一两年的主要业务规划是什么？

二、薪酬与绩效

  1. 月薪具体由哪些部分组成？固定工资和绩效工资分别是多少？
  2. 绩效系数或绩效等级如何计算？系数仅作用于绩效工资，还是会影响整个月度工资？
  3. 绩效考核周期是季度还是年度？绩效等级如何划分，是否与奖金、调薪和晋升挂钩？
  4. 年终奖通常是几个月？固定发放还是根据个人绩效、部门和公司经营情况浮动？往年实际发放情况如何？
  5. 年终奖是否要求发放日仍在职或服务满一定期限？入职不满一年是否按在职月份折算？
  6. 试用期期间薪资是否打折？绩效工资和年终奖是否正常参与？
  7. 工资通常每月几号发放？年度调薪和薪酬评估通常多久进行一次？
  8. Offer 中的年薪按多少薪计算？月薪、绩效和奖金等关键待遇能否在书面 Offer 或附件中明确？

三、试用期与应届生政策

  1. 试用期具体几个月？转正考核依据哪些指标，是否有明确标准和阶段性反馈？
  2. 转正考核未通过通常如何处理？是否有沟通改进或其他处理流程？
  3. 近几年校招生整体转正情况如何？是否存在统一的转正淘汰机制？
  4. 校招应届生是否有专门培养机制、导师带教、培训计划或新人培养周期？
  5. 是否需要签订三方就业协议？是否有违约金，解除或变更流程是什么？
  6. 如果毕业时间或预计入职时间发生变化，公司是否支持调整？入职需要提前准备哪些材料？

四、五险一金、落户与人才政策

  1. 五险一金按照什么基数缴纳？公积金缴纳比例是多少？是否按照实际工资作为缴纳基数？
  2. 公司是否配合应届毕业生办理当地落户？具体需要提供哪些材料？
  3. 近两年是否有同批次校招生成功落户的案例？是否存在名额、学历或其他资格限制？
  4. 公司是否协助申请人才补贴、租房补贴或应届生专项政策？相关资格和办理流程是什么？

五、年假、福利、工作时间与出差

  1. 年假按照自然年还是入职周年计算？是否支持跨年结转？
  2. 加班调休的有效期是多久？过期是否清零？周末加班如何补偿？
  3. 部门正常上下班时间是怎样的？实行双休还是其他工作制度？平时和周末加班频率如何？
  4. 公司是否提供餐补、房补、交通补贴、打车报销等福利？
  5. 是否有补充商业保险、年度体检、节假日福利等？
  6. 岗位平均每年出差多少次？单次一般持续多久？住宿、交通、餐补和差旅补贴标准是什么？

六、职业发展、内部转岗与劳动合同

  1. 入职后的岗位职级是什么？直接汇报对象是谁？是否有独立的技术职级晋升通道？
  2. 公司是否支持跨团队转岗？正式流程、转岗冷却期、重新面试和试用期处理规则是什么？
  3. 劳动合同签约主体是哪家公司？合同期限是几年？工作地点是否可能发生变化？
  4. 是否需要签订竞业限制协议？期限、适用范围和补偿标准是什么？
  5. 是否有培训服务期、培训费用返还或其他附加协议义务？
