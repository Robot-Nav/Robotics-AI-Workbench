# Offer 沟通助手

**在线地址：** https://robot-nav.github.io/Robotics-AI-Workbench/tools/offer-assistant/

## 功能

- 按岗位与技术发展、薪酬绩效、试用期与应届生政策、五险一金与落户、福利与工作时间、职业发展与劳动合同六个模块整理 Offer 沟通问题。
- 勾选确认状态、记录 HR / 技术负责人答复，搜索和筛选问题。
- 复制待确认问题或单个模块的问题。
- 导出完整沟通清单和答复备注。
- 使用浏览器麦克风录音，并在支持的浏览器中实时进行普通话语音转写。
- 下载录音文件、复制或导出转写文字。

## 使用方式

1. 使用 HTTPS 在线地址打开页面。
2. 勾选“已告知沟通对象并取得录音同意”。
3. 点击“开始录音”，按浏览器提示授权麦克风。
4. 沟通结束后点击“结束录音”，再点击“下载音频”保存录音。
5. 转写文字可手动修正；可单独导出文字，也可随 Offer 清单一起导出。

## 录音、转写与隐私说明

- 页面不会偷偷启动录音。必须由用户主动点击开始、授予麦克风权限，并确认已告知沟通对象且取得同意。
- 音频仅暂存在当前页面内存中，不会上传到本网站、GitHub 仓库或本项目自建服务器。结束后需要手动下载；关闭页面前请先保存。
- 清单勾选状态、备注和转写文字保存在当前浏览器本地。更换设备或清理浏览器数据前，请导出备份。
- 实时转写使用浏览器的 Speech Recognition API。不同浏览器支持情况不同，部分实现可能调用浏览器厂商的在线识别服务并需要网络；本工具不承诺离线语音识别。
- 若浏览器不支持实时转写，仍可使用录音功能，下载音频后再通过其他转写工具处理。
- 网页切换到后台或手机锁屏后，浏览器/操作系统可能暂停录音或转写。网页无法保证持续后台录音；建议保持页面前台打开。
- 建议优先使用最新版 Chrome 或 Edge，并通过 HTTPS 访问。

## 技术实现

纯 HTML、CSS、JavaScript，无需后端服务。录音使用 MediaRecorder，实时转写在浏览器支持时使用 Speech Recognition API。
