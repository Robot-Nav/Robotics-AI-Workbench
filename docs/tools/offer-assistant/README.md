# Offer 沟通助手

**在线地址：** https://robot-nav.github.io/Robotics-AI-Workbench/tools/offer-assistant/

## 功能

- 按公司建立独立 Offer 档案，记录公司名称、岗位、地点、求职进度、联系人和档案备注。
- 每家公司独立保存问题确认状态、HR 答复备注和沟通转写，不会混在一起。
- 支持新建、切换、编辑和删除公司档案。
- 导出当前公司档案 JSON，或一次性备份全部公司；支持从备份文件导入。
- 按岗位与技术发展、薪酬绩效、试用期与应届生政策、五险一金与落户、福利与工作时间、职业发展与劳动合同六个模块整理 Offer 沟通问题。
- 搜索和筛选问题，复制待确认问题或单个模块的问题。
- 使用浏览器麦克风录音，并在支持的浏览器中实时进行普通话语音转写。
- 下载录音文件、复制或导出转写文字。

## 使用方式

1. 使用 HTTPS 在线地址打开页面。
2. 在页面顶部点击“新建”，为每家公司建立独立档案；填写公司名称、岗位、地点和沟通进度。
3. 切换公司档案后，对应的确认状态、答复备注和转写文字会自动切换。
4. 定期点击“导出当前档案”或“备份全部档案”，保存 JSON 备份。更换设备或浏览器前，先备份，再在新设备导入。
5. 如需录音，先告知沟通对象并取得同意，再勾选页面中的录音同意确认。
6. 点击“开始录音”，按浏览器提示授权麦克风；结束后点击“结束录音”，再点击“下载音频”保存音频文件。
7. 转写文字可手动修正；可单独导出文字，也可随公司档案一起导出。

## 同一部手机拨打电话时的录音限制

网页的 `getUserMedia + MediaRecorder` 只能申请麦克风输入，不能直接读取蜂窝电话系统中的通话上下行音频。因此，在同一部手机上打开网页并拨打普通电话，不能保证录到 HR 和自己的双方通话声音；通话期间操作系统还可能暂停或独占麦克风。

建议按以下顺序处理：

1. **优先使用手机系统自带的通话录音功能**（若设备、拨号应用和所在地区支持），录音后将音频文件导入或单独保存。
2. 如果手机不支持通话录音，使用手机免提通话，并在电脑上打开 Offer 助手录音；先做短测试，确认双方声音都能清晰收录。
3. 也可以使用第二台设备录音，或使用双方同意且提供录音功能的会议/网络电话服务。

普通网页无法保证手机锁屏或切换到后台后持续录音。不要依赖网页麦克风录音替代系统级电话录音。

## 录音、转写与隐私说明

- 页面不会偷偷启动录音。必须由用户主动点击开始、授予麦克风权限，并确认已告知沟通对象且取得同意。
- 音频仅暂存在当前页面内存中，不会上传到本网站、GitHub 仓库或本项目自建服务器。结束后需要手动下载；关闭页面前请先保存。
- 公司档案、清单勾选状态、答复备注和转写文字保存在当前浏览器本地。删除公司档案会同时删除该公司的本地清单和转写文字。
- 导出的 JSON 备份包含公司档案信息、清单状态、答复备注和转写文字，不包含音频文件；录音音频需要单独下载备份。
- 更换设备或清理浏览器数据前，请先导出备份。不要在公共电脑上保存包含个人隐私或企业敏感信息的记录。
- 实时转写使用浏览器的 Speech Recognition API。不同浏览器支持情况不同，部分实现可能调用浏览器厂商的在线识别服务并需要网络；本工具不承诺离线语音识别。
- 若浏览器不支持实时转写，仍可使用录音功能，下载音频后再通过其他转写工具处理。
- 网页切换到后台或手机锁屏后，浏览器/操作系统可能暂停录音或转写；建议保持页面前台打开。
- 建议优先使用最新版 Chrome 或 Edge，并通过 HTTPS 访问。


## 隐藏录音入口与密码验证

- 页面默认隐藏录音、麦克风和实时转写控件；普通 Offer 档案功能不受影响。
- 在页面底部点击“隐藏入口”，首次使用时自行设置至少 8 位访问密码；之后输入密码才会显示录音区域。
- 解锁后可点击“隐藏录音”立即重新锁定；刷新或重新打开页面后也会默认锁定。
- 密码使用浏览器 Web Crypto 的 PBKDF2-SHA-256 派生校验值，并配合随机盐保存在当前浏览器本地，不会将明文密码提交到 GitHub 或网站服务器。
- 密码设置按浏览器本地生效，不会跨设备同步。更换设备需要在新设备单独设置；清除该站点浏览器数据可能导致本地密码校验记录被清除，需要重新设置。
- **安全边界：** 本站部署在公开 GitHub Pages，录音界面密码门是防止普通访客误操作或随手访问的本地界面锁，不是服务器身份认证。具备开发者工具或能修改浏览器本地数据的人仍可能绕过前端限制；不要把它用于保护高度敏感的录音资料。若需要真正只允许本人访问，应改用带服务器端账号认证的私有服务。

## 技术实现

纯 HTML、CSS、JavaScript，无需后端服务。录音使用 MediaRecorder，实时转写在浏览器支持时使用 Speech Recognition API；公司档案及其清单/转写数据按档案 ID 在浏览器本地隔离存储。
