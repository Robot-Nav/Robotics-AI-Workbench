# Offer 沟通助手

**在线地址：** https://robot-nav.github.io/Robotics-AI-Workbench/tools/offer-assistant/

Offer 沟通助手用于整理校招求职过程中的沟通问题，按公司维护独立档案，方便对比不同岗位的工作内容、薪酬待遇、培养机制和职业发展情况。

## 主要功能

- **独立公司档案：** 每家公司单独建立档案，记录公司名称、应聘岗位、工作地点、求职进度、联系人和备注。
- **结构化沟通清单：** 将需要确认的问题按岗位职责、薪酬绩效、试用期与应届生政策、五险一金与落户、福利与工作时间、职业发展与劳动合同等模块分类整理。
- **答复备注：** 记录沟通结果和后续需要确认的事项。
- **进度管理：** 标记问题确认状态，快速筛选尚未确认的问题。
- **档案备份：** 支持导出单家公司档案、备份全部公司档案，以及从备份文件恢复数据。

## 使用方式

1. 打开上方在线地址。
2. 点击“新建”，为每家公司建立独立档案。
3. 填写岗位、地点、联系人和当前求职进度。
4. 按模块查看沟通问题，结合实际情况记录答复和待办事项。
5. 定期导出当前档案或备份全部档案，便于后续整理和对比。

## 数据管理

公司档案和沟通备注保存在当前浏览器中。更换设备或浏览器前，建议先使用“备份全部档案”导出文件，并在新设备中通过导入功能恢复。
