# 工具箱

这里放置可直接使用的轻量工具，和算法原理、项目源码文档分开维护。

## 当前工具

- **[Offer 沟通助手](https://robot-nav.github.io/Robotics-AI-Workbench/tools/offer-assistant/)**：按公司独立管理 Offer 档案，整理沟通问题、记录 HR 答复、录音与实时转写，并支持 JSON 备份和迁移。
- [Offer 沟通助手使用说明](offer-assistant/README.md)

工具以静态网页形式部署在 GitHub Pages。公司档案、问题清单和文字记录默认保存在使用者当前浏览器本地；录音音频需要单独下载保存，不会提交到公开仓库。
