# 项目实践

项目记录以可复现和可验收为目标。每个项目至少应说明：

1. 要解决的问题与非目标。
2. 系统架构和模块接口。
3. 关键算法与设计取舍。
4. 构建、运行和部署命令。
5. 测试场景与评价指标。
6. 结果证据、已知限制和后续计划。

建议把项目代码放在独立仓库，本站维护项目说明、技术决策、实验报告和问题索引。
