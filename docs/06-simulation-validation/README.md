# 仿真、验证与部署

机器人 AI 的有效性必须通过可重复实验验证。训练奖励或单次演示不能代替系统级评估。

## 仿真平台

- Isaac Sim / Isaac Lab：机器人场景、传感器仿真和并行训练。
- MuJoCo：多体动力学、接触仿真和控制算法研究。
- Gazebo：ROS 生态集成与机器人系统仿真。

## Sim2Real 差异

- Model Gap：动力学模型不准确。
- Friction Gap：摩擦和接触条件不同。
- Actuator Gap：执行器延迟、死区和饱和。
- Sensor Gap：噪声、频率、视场和标定误差。
- Latency Gap：通信、推理和控制链路延迟。

## 验证要求

固定随机种子和配置，记录代码 Commit、场景版本、参数、指标、日志和失败样例。
