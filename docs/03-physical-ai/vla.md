# Vision-Language-Action（VLA）

VLA 模型尝试将视觉观测、语言指令和机器人状态映射为机器人动作或动作序列。

## 常见组成

1. 视觉编码器提取图像或多视角特征。
2. 语言编码器表示任务指令。
3. 状态编码器融合关节、末端或底盘状态。
4. 跨模态融合模块形成条件表示。
5. 动作头输出离散 Token、连续动作或 Action Chunk。

## 重点问题

- 动作空间如何定义：关节位置、关节速度、末端位姿或底盘速度。
- Action Chunk 长度与控制频率如何匹配。
- 数据是否覆盖不同物体、场景、视角和失败情况。
- 如何进行动作限幅、碰撞检查和安全降级。

评估时应记录任务成功率、泛化场景、动作平滑性、推理延迟和人工干预次数。
