# 从这里开始

Robotics AI Workbench 是长期维护的个人技术工作台，以机器人系统为核心应用场景，同时覆盖 AI Agent、Physical AI、AI 工程化和自动化研发。

## 内容组织

- **技术知识**：原理、方法、公式、优缺点和适用边界。
- **实践记录**：代码、命令、配置、实验和结果。
- **问题知识库**：问题现象、环境、根因、修复与验证。
- **项目**：端到端系统、技术架构和可复现实验。
- **研究资料**：论文解读、开源项目和技术对比。

## 推荐学习闭环

提出问题 → 查阅资料 → 理解原理 → 动手实现 → 测试验证 → 记录问题 → 沉淀方法。

重要结论应经过官方文档、论文、源码或实验验证。
