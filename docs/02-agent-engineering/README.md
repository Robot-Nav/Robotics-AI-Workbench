# Agent Engineering

研究如何让 AI 从回答问题转变为能够使用工具、执行任务、维护状态并完成闭环工作的系统。

## 核心组成

- **Model**：负责理解、推理和生成下一步决策。
- **Context**：任务目标、项目规则、历史状态和检索到的资料。
- **Tools**：文件、终端、Git、仿真器、测试和外部服务。
- **Orchestration**：任务拆解、执行顺序、重试、交接和审批。
- **Evaluation**：检查任务是否真正完成，而不只是输出看起来合理。

## 机器人研发中的应用

让 Agent 阅读 ROS 2 仓库、分析节点通信、定位算法入口、修改代码、运行编译测试、解析日志并生成实验报告。
