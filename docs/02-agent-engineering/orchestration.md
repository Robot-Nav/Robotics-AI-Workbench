# 多 Agent 编排

## 常见角色

| 角色 | 职责 |
|---|---|
| Planner | 拆解目标、生成任务依赖 |
| Researcher | 检索论文、文档和源码 |
| Coder | 实现代码与测试 |
| Reviewer | 检查逻辑、接口和风险 |
| Tester | 编译、执行测试、分析结果 |
| Supervisor | 管理状态、分配任务和验收 |

## 设计原则

- 先明确共享状态和交付物，再拆分 Agent。
- 并行任务之间应尽量减少共享文件冲突。
- 每个 Worker 必须返回证据和未解决事项。
- 合并代码前执行测试和 Review。
- 对不可逆或影响真机安全的动作保留人工审批。
